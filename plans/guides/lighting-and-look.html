Schooner — Lighting & Look Guide

How the renderer turns components and resources into a final image, what every look-affecting parameter does, and how to combine them to hit a specific mood. Written against the engine as it stands in Game 1 (Kinesis).

There are four places you reach to change how the scene looks, and they layer in a strict order. Knowing the order is most of the battle — a parameter that looks "broken" is usually a parameter being undone by a later layer.

0The mental model — how a pixel is built

Every frame runs three passes. Only the order matters for now; the budgets are covered in their sections.

Pass 1
Shadow
Depth-only render from each Shadowcaster spot's point of view into a 1024² depth map. No colour. Produces the "who is occluded" data the forward pass samples.
→
Pass 2
Forward → HDR
Every opaque (then transparent) mesh shaded with Blinn–Phong against all lights, with shadows, height-fog and god-rays folded in. Writes linear HDR to an offscreen texture.
→
Pass 3
Post → screen
One fullscreen triangle: tonemap → colour grade → vignette → overlay → clamp. The sRGB swap-chain does the gamma encode on present.

Inside the forward shader, the colour of one fragment is assembled like this — read it top to bottom, it is the order the knobs apply:

// inside the forward fragment shader (forward.wgsl)
albedo = material.albedo × texture(uv) // tint × sampled colour
scene = ambient + lit + emissive
         ambient = albedo × directional.ambient // flat, every fragment
         lit = Σ blinn_phong(dir, spots, points) // N·L diffuse + spec, ×shadow, ×cone, ×atten
         emissive = material.emissive × intensity // own light, ignores shadow & ambient

final = mix(fog.color, scene, transmittance) + god_ray_sum // HDR, still linear

// then the post pass, per pixel:
out = clamp( overlay( vignette( grade( aces(final) ) ) ) )
Why this matters in practice. Three recurring "bugs" that are really the order working as designed:
  • "My emissive lamp won't get darker in fog." It does — fog's mix runs after emissive is added, so a glowing lamp behind dense fog correctly fades to a coloured haze. If it isn't fading, your fog density or distance is too low, not your emissive.
  • "My grade looks weak." Grade runs after ACES tonemap, on values already squashed into [0,1]. It nudges an LDR image; it can't recover blown highlights. That's intentional (the numbers stay film-portable) — push intensity/ambient if you want more range to grade.
  • "My normal map does nothing." normal_strength only bites when a normal_texture is actually bound; with none, the engine binds a flat identity map and the strength multiplies zero relief. (The chamber walls in playground.rs currently have their normal_texture line commented out — normal_strength: 0.6 there is dormant.)

1Material — the per-surface knobs

component Material is an optional component. A mesh entity with no Material renders against Material::DEFAULT: white albedo, mid roughness, opaque, no glow. Add the component and set only the fields you care about with ..Material::DEFAULT (or ..Default::default()).

FieldType / rangeDefaultWhat it does to the look
albedoVec3, linear 0–1 (can exceed)1,1,1Base surface colour. Multiplied into the sampled texture — so with a texture it tints, without one it is the colour. Linear values: 0.02 is near-black paint, 0.5 mid-grey.
roughnessf32, 0–10.5Specular lobe width (a Blinn–Phong analogue, not PBR). Low = tight bright highlight (polished), high = broad dim (matte). Maps to shininess 2^(10·(1−r)): r0→1024, r0.5→32, r1→1.
emissiveVec3, linear0,0,0The surface's own light. Added outside lighting — survives shadow, ignores ambient. Lamps, gel, the eye behind glass.
emissive_intensityf32, ≥00.0Multiplier on emissive. Push past 1 for a hot glow that ACES rolls off softly and trips the bloom bright-pass (§5.4) — brighter = bigger halo. Glow only — it does not light neighbours (no GI).
blendOpaque / AlphaBlendOpaqueSelects the pipeline. Opaque uses REPLACE (ignores alpha). AlphaBlend uses the over-operator and is double-sided (no back-face cull).
opacityf32, 0–11.0Coverage, multiplied into texture alpha. Only meaningful under AlphaBlend — an Opaque material stays solid whatever this says. Lets a flat-tinted pane fade without an alpha texture.
fresnelf32, 0–10.0Schlick rim. 0 = matte dielectric. Above 0, lifts both specular and alpha toward 1 at grazing angles via (1−n·v)^5. The single knob that turns a translucent pane into glass: clear face-on, reflective & opaque at the silhouette.
albedo_textureOption<TextureHandle>NonesRGB colour texture, multiplied into albedo. None binds a WHITE 1×1 so the multiply is a no-op.
uv_scaleVec21,1Per-axis tiling: (4,2) repeats 4× across U, 2× across V. Per-axis keeps texels square on non-square walls. In triplanar mode, uv_scale.x is reused as world repeats-per-metre (y/offset ignored).
uv_offsetVec20,0Translation after scale: uv·scale + offset. Pick an atlas sub-rect or shift a decal without re-authoring mesh UVs.
normal_textureOption<TextureHandle>NoneLinear data texture (not sRGB!). None binds FLAT_NORMAL (0,0,1) = identity. Must be loaded via the linear path (load_png_linear).
normal_strengthf32, ~0–11.0Scales tangent-space xy before the TBN rotate. 0 = flat, 1 = full relief. Keep low (0.3–0.6) for the HL2/Gothic "subtle relief raked by hard light" look. No-op when no normal map is bound.
triplanarboolfalseWorld-space projection instead of mesh UVs — texture is continuous across separately-spawned boxes, no seams, no thin-reveal stretch. The right mode for procedural architecture (walls/floors). false for authored meshes (the eye).
depth_biasf32, world metres0.0Nudges the surface toward the camera along the view ray before the depth test — screen position unchanged, depth shrinks. A few mm lets a coplanar decal win depth_compare: Less against its host wall without floating off it.

How roughness reads — the shininess curve

polished metal / glassmatte stone / cloth

Quick reads

  • 0.1 — wet/polished. Tiny brilliant glint that moves fast as you walk.
  • 0.2–0.35 — brushed/worn metal. Visible but spread highlight. (Chamber floor uses 0.35, walls 0.2.)
  • 0.5 — the neutral default; reads like the pre-Material baseline (≈shininess 32).
  • 1.0 — chalk/concrete. Highlight collapses into diffuse; almost pure Lambert. (Lab outer walls use 1.0.)

Worked material recipes

Brushed-metal wall (procedural architecture)

Material {
  albedo_texture: Some(iron_albedo),
  normal_texture: Some(iron_normal),  // linear upload
  normal_strength: 0.6,               // raked, not bumpy
  roughness: 0.2,
  triplanar: true,                    // seamless across boxes
  uv_scale: Vec2::splat(1.0/2.0),     // 1 repeat / 2 m
  ..Material::DEFAULT
}

Triplanar is what makes a wall built from many spawn_box slabs look like one continuous surface. uv_scale.x = repeats/metre here.

Frosted glass pane

Material {
  albedo: Vec3::new(0.6, 0.7, 0.8),  // cool tint
  albedo_texture: Some(glass),
  roughness: 0.1,                    // smooth → tight glint
  opacity: 0.2,                      // mostly clear
  blend: BlendMode::AlphaBlend,
  fresnel: 1.0,                      // THE glass knob
  ..Material::DEFAULT
}

The triad is AlphaBlend + low opacity + fresnel: 1.0. Fresnel lifts the silhouette to reflective/opaque while the centre stays clear — that edge-bright contrast is what reads as glass rather than a grey film.

Emissive lamp / glowing gel

Material {
  emissive: Vec3::new(1.0, 0.1, 0.05),
  emissive_intensity: 3.0,  // past threshold → blooms (§5.4)
  roughness: 0.5,
  ..Material::DEFAULT
}

// wet glowing food gel: glow + glassy translucency
Material {
  albedo: Vec3::new(0.5, 0.45, 0.12),
  emissive: Vec3::new(0.95, 0.85, 0.25),  // sulfur-gold
  emissive_intensity: 2.5,
  roughness: 0.15, opacity: 0.8, fresnel: 1.0,
  blend: BlendMode::AlphaBlend,
  ..Material::DEFAULT
}

Glow only — it will not light the wall beside it (no GI). To actually illuminate, pair the emissive mesh with a co-located PointLight of the same colour. The higher the emissive_intensity, the bigger the bloom halo (§5.4).

Coplanar decal (sign on a wall)

Material {
  albedo_texture: Some(decal),
  blend: BlendMode::AlphaBlend,
  depth_bias: 0.005,        // 5 mm toward camera
  ..Material::DEFAULT
}

Without depth_bias, a quad sitting exactly on a wall z-fights into shimmer. The bias nudges depth only — the decal stays visually flush.

2Lights — direction, colour, intensity, reach

Three light components, all sharing one principle: tint (color, unit magnitude) is split from brightness (intensity, a scalar). Recolour without re-tuning brightness and vice-versa. The rough per-fragment contribution is:

contribution ≈ albedo × color × intensity × attenuation × max(N·L, 0)

2.1 DirectionalLight positionless

An infinitely-distant sun. The renderer uses the first one it finds. It carries its own direction and does not pair with a Transform. It also carries the scene's ambient.

FieldDefault (::sun())Note
direction(-0.4, -1.0, -0.3)Direction the light travels (sun→surface). Shader normalizes & negates. Down-and-forward by default.
color1,1,1Unit tint.
intensity1.0Scalar. Set to 0 to use the light purely as an ambient carrier (see below).
ambient0.1,0.1,0.1Flat term added to every fragment regardless of normal. A cheap stand-in for indirect light. Read unconditionally — even when intensity = 0.
The ambient-carrier trick. Indoor Kinesis chambers have no sun, but they still need fill so shadow-side surfaces aren't pure black. The playground spawns a DirectionalLight with intensity: 0.0 and ambient: (0.18,0.20,0.26) — no directional contribution, just a cold lifted ambient. Raising ambient is your master "lift the whole room toward over-lit" dial; pushing it blue-grey is the "birch → clinical" move. It lifts everything without flattening the hard raking spot, because the spot still carves the relief that flat ambient can't.

2.2 SpotLight Transform sibling

A cone. Authoring contract: spawn with both a SpotLight and a Transform. Position = Transform.translation; direction = Transform.rotation · NEG_Z (shines along local −Z). Aim by rotating the transform — spawn_spot does this for you with Quat::from_rotation_arc(NEG_Z, dir).

SpotLight::new(color, intensity, range, inner_deg, outer_deg)
  // e.g. surgical white interrogation lamp:
  SpotLight::new(Vec3::new(0.92, 0.96, 1.0), 28.0, range, 42.0, 60.0)
    .with_god_ray_intensity(1.4)
ParamDefaultWhat it controls
color1,1,1Unit tint. Faintly-blue ≈ fluorescent; faintly-amber ≈ tungsten.
intensity1.0Scalar brightness. Goes high (10–30) because inverse-square falloff eats most of it before it reaches the floor.
range10.0Soft cutoff distance. Also sets the shadow far-plane — keep it tight to the geometry you actually light, or shadow depth precision wastes range.
inner_deg20°Half-angle of the full-strength core.
outer_deg30°Half-angle where it reaches zero. Gap between inner/outer = softness of the cone edge. Also sets the shadow-map FOV (= 2×outer).
god_ray_intensity1.0Per-spot multiplier on the fog's scattering (volumetric beam). 0 disables this spot's beam; 1.4 makes it the hero. See §4.

Cone & attenuation

Two falloffs multiply together inside the cone:

cone = smoothstep(cos·outer, cos·inner, dot(L,dir))
atten = window² / (1 + d²)
window = max(1 − (d/range)⁴, 0)

The 1/(1+d²) is physical inverse-square (with a guard near the lamp); the window term tapers it cleanly to zero at range so the lit pool doesn't end on a hard ring. This is the UE4/Frostbite shape.

2.3 PointLight Transform sibling

Omnidirectional. Pairs with a Transform; only translation is read. Same windowed inverse-square attenuation as the spot, no cone. No shadows (would need cube maps — out of scope for Kinesis).

PointLight::new(color, intensity, range)
  // red service light deep in a tunnel:
  PointLight::new(Vec3::new(1.0, 0.06, 0.03), 6.0, tunnel_length)

Caps: up to 8 spot + 16 point lights per frame (overflow is warn-and-dropped). Use points for cheap coloured accents — they don't carry the cone/shadow cost.

3Shadows — the Shadowcaster marker

marker component Attach Shadowcaster to a SpotLight entity to opt it into the depth pass. Lights without it pay zero shadow cost. Only spots cast; points never do.

PropertyValueNote
Max simultaneous casters4MAX_SHADOW_CASTERS. Indoor rooms rarely want >1. Overflow dropped.
Map resolution1024²Depth32Float, 4 MB each. Tuned for 6–10 m chamber casts.
Frustum FOV2 × outer_degDriven by the spot's outer cone.
Far planespot.rangeWhy a tight range = better shadow precision.

Acne & peter-panning are already handled. The pipeline uses no-cull + normal-offset bias (scaled by 1−n·l, so grazing surfaces get more offset) plus a small slope-scaled rasterizer bias. You shouldn't need to fight shadow acne by hand; if you see it, the lever is the spot's range (precision) and the F1 kernel (softness), not a bias constant in the scene.

To make a spot "read as equipment, not cinematography": mount it slightly off-centre, aim near-straight-down, give it a tight cone and a high intensity so it rakes across the floor producing long hard shadows. The playground's hero lamp does exactly this.

4Fog & god-rays — the atmosphere

resource Fog is one per-scene resource that does two jobs: height-fog (depth haze) and god-rays (volumetric beams through spot cones). Default is off (density = 0 short-circuits everything).

FieldRoleWhat raising it does
colorHeight fogRGB the room dissolves into at distance ("what's behind the haze"). Linear.
densityHeight fogThickness at base_height. 0 disables fog AND god-rays. The master switch.
base_heightHeight fogWorld-Y where density = density. Above it, density falls off exponentially.
falloffHeight fogHow fast fog thins with height (1/units). 0 = uniform soup at all heights; higher = a dense layer pooled on the floor that thins overhead (the Gothic/Witcher mood).
scatteringGod-raysGlobal beam brightness — single-scatter coefficient. Multiplied per-spot by god_ray_intensity.
Why density and scattering are separate knobs. Physically, doubling density doubles both extinction and scattering. Games split them (UE/Frostbite do too) because authors want two independent moods: "thick atmosphere, subtle glow" (high density, low scattering) and "thin air, bright god-rays" (low density, high scattering). The god-ray term still multiplies by density-at-point, so density = 0 correctly kills beams regardless of scattering.

How the height-fog blends

τ = optical depth along view ray (exponential-height integral, Wenzel 2007)
transmittance = exp(−τ)
final = mix(fog.color, scene, transmittance) // τ=0 → all scene; τ large → all fog

The blend happens in HDR linear space before tonemap — so heavily-fogged frames tonemap gracefully, and emissive surfaces correctly dim through fog (a red lamp behind haze reads as red haze, not a hot spot poking through).

God-rays — the per-spot beam dial

God-rays are computed analytically (ray–cone intersection, single midpoint sample — no raymarch, ~10 instructions/spot/fragment). They're additive on top of the foggy scene. To get a visible beam you need all three: fog density > 0, fog scattering > 0, and the spot's god_ray_intensity > 0. The playground's hero lamp uses .with_god_ray_intensity(1.4) against a thin cold scattering: 0.25 medium.

Known limitation. God-rays don't yet respect volumetric shadow occlusion — a wall in front of the cone clips the beam (via the view-ray length), but a wall inside the cone won't carve a shadow notch out of the beam. That's deferred to Game 2A+. Keep beams in open cone volumes for now.

5.1 ColorGrade — ASC CDL resource

graded = (color × gain + lift) ^ (1 / gamma)
FieldIdentityEffect
lift0,0,0Shadow shift (the toe). Per-channel tint of the darks. Tiny values — 0.02 on blue is already a visible cold cast.
gamma1,1,1Mid-tone reshape via pow(x, 1/gamma). >1 brightens that channel's mids, <1 darkens. Must stay strictly positive (0 → NaN).
gain1,1,1Highlight multiplier (the shoulder). Per-channel tint of the brights.
Why grade runs after tonemap. ACES first, grade second — so the numbers you author map to what you see on screen, not to HDR scene-linear values that change shape under the curve. Bonus: the lift/gamma/gain triple is literally ASC CDL, so a colourist can paste the same numbers into DaVinci and get the same look.

5.2 Vignette resource

Radial darken from centre to corners, elliptical (tracks aspect ratio). Separate from grade because vignette is a compositor/mood tool often modulated independently (heavier in tense moments) while the grade — the scene's look — stays put.

FieldOffEffect

5.3 PostOverlay resource

A fullscreen texture composited last. Three blend modes, fixed up front so a later effect can't need one the slot can't express. Gated entirely by intensity (0 = off, whatever texture is bound).

5.4 Bloom — the faint highlight glow resource

A soft glow around the over-bright parts of the frame, added back into the HDR image before the tonemap (unlike grade/vignette/overlay, which run after). Modern dual-filter pyramid (COD:AW 2014) tuned for the 2005–2009 look it references — HL2, Witcher 1 — so it's a wide warm halation, not a tight modern flare. Faint by default; the full "everything glows" end of the dial exists for one scene, never as the resting state.

What blooms is brightness, not identity. The bright-pass keeps only pixels whose HDR radiance exceeds threshold — there's no per-object bloom flag. To make a thing glow more, make it brighter: raise its emissive_intensity (or a light's intensity) past the threshold. That's how the era authored it. Because the add is pre-tonemap, the glow rolls through the same ACES shoulder as every other highlight.
FieldDefaultEffect
enabledtrueMaster gate. Off skips the GPU pyramid build entirely and adds nothing.
strength0.04Master "how much." Additive, so small: 0.04 faint, 0.4+ everything glows.
threshold1.1HDR cutoff. ≥1 = only genuinely over-bright pixels; below 1 hazes midtones.
knee0.5Soft ramp into the threshold (fraction of it) so surfaces fade into bloom instead of popping.
filter_radius2.0Blur spread. 1 = tight, 2–3 = the wide soft era halo.
tint1,.95,.85Warm cast multiplied into the glow — the golden-hour feel.

Presets: OFF · FAINT (the restrained default) · ERA_GLOW (pronounced HL2/Witcher halation) · EVERYTHING_GLOWS (deliberate white-out). Cycle live with F7.

6Colour space — the one rule that bites

Albedo/colour textures are sRGB. Normal maps (and any data texture) are linear. Load them down the right path or the look breaks:
  • Colour (albedo, glass, decals): load_png → uploaded Rgba8UnormSrgb. The GPU decodes to linear at sample time, so the shader does no manual pow(rgb, 2.2).
  • Data (normal maps): load_png_linear → uploaded Rgba8Unorm. A normal decoded through sRGB would skew the relief direction. The scene's TextureAsset::is_data() routes this.

Uniform colours you write in Rust (light color, material albedo, fog color, grade) are already linear — write the linear value directly, the shader doesn't convert them. The final sRGB encode happens once, on present, by the swap-chain format. Symptoms of getting it wrong: "lighting looks washed out / too dark", "normal map relief points the wrong way". Two normal conventions exist — this engine expects OpenGL (+Y up) normal maps (note MetalFloorNormal deliberately uses the NormalGL variant, not the DX sibling).

7Situation cookbook — combining everything

Each situation pulls all four layers at once. These mirror and extend the playground.rs build so you can read the working example beside them.

A · Hostile clinical lab (the current playground)

Goal: over-lit interrogation room, cold and aggressive, one hard hero lamp carving relief, a thin cold haze.

// Atmosphere + post (scene resources)
world.insert_resource(ColorGrade::CHAMBER_WHITE);   // or CLINICAL_COLD for harsher
world.insert_resource(Vignette::CINEMATIC);
world.insert_resource(Fog { color: (0.05,0.06,0.08), base_height: 0.0,
                            density: 0.03, falloff: 0.3, scattering: 0.25 });

// Ambient carrier: cold, lifted, no directional contribution
DirectionalLight { intensity: 0.0, ambient: (0.18,0.20,0.26), ..default }

// Hero lamp: cool-white, high intensity (1/d²), tight, raking, shadowed, strong beam
spawn_spot(.., SpotLight::new((0.92,0.96,1.0), 28.0, range, 42.0, 60.0)
                  .with_god_ray_intensity(1.4), /*casts_shadow=*/ true);

The moves: high ambient pushes the room toward white; the cold tint is in both ambient and grade; the single raking spot keeps shadows hard despite the high fill; thin fog + 1.4 god-ray gives the lamp a visible cold beam without fogging the room into soup.

B · Cozy warm cage

Goal: the comfort end of the attitude axis — soft, amber, enclosing.

world.insert_resource(ColorGrade::CAGE_WARM);
world.insert_resource(Vignette::CINEMATIC);
world.insert_resource(Fog { color: (0.10,0.07,0.04), density: 0.02,
                            falloff: 0.4, scattering: 0.15, base_height: 0.0 });

DirectionalLight { intensity: 0.0, ambient: (0.16,0.12,0.08), ..default } // warm fill
// Soft wide tungsten point/spot, lower intensity, wide cone, maybe no shadow
SpotLight::new((1.0,0.85,0.6), 12.0, range, 35.0, 60.0)

Inverse of A: warm ambient, warm grade, wider/softer/dimmer light, gentler vignette. Lower roughness contrast on surfaces reads softer too.

C · Red service corridor

Goal: tense, low, dominated by a red point source.

world.insert_resource(ColorGrade::SERVICE_RED);
world.insert_resource(Vignette::OPPRESSIVE);   // crush corners, tunnel vision
world.insert_resource(Fog { color: (0.06,0.01,0.01), density: 0.05, falloff: 0.2, ..});

DirectionalLight { intensity: 0.0, ambient: (0.06,0.02,0.02), ..default } // near-dark
spawn_point(.., PointLight::new((1.0,0.06,0.03), 6.0, range));

Low ambient lets the red point dominate; SERVICE_RED grade biases even neutral surfaces red; OPPRESSIVE vignette adds threat. No shadow caster — points can't, and the dark already hides the lack.

D · Volumetric beam-lit chamber (god-ray hero shot)

Goal: a single dramatic shaft of light through thin air — beam over haze.

// Thin medium, BRIGHT scattering — "thin air, strong god-rays"
Fog { color: (0.02,0.02,0.03), density: 0.015, falloff: 0.5, scattering: 0.6 }

DirectionalLight { intensity: 0.0, ambient: (0.04,0.04,0.05), ..default } // dim, beam dominates
spawn_spot(.., SpotLight::new((1.0,0.98,0.92), 30.0, range, 8.0, 16.0)  // TIGHT cone
                  .with_god_ray_intensity(2.0), true);

The dial for a sharp shaft: low density (clear air so the beam edges stay crisp), high scattering × high god_ray_intensity, a tight inner/outer cone, and low ambient so the beam isn't washed out. Mind the limitation: no in-cone wall will notch the beam yet.

9Cheat sheet — which knob for which symptom

Brightness / exposure

  • Whole room too dark → raise DirectionalLight.ambient (the master fill).
  • Lit pool too small/dim → raise spot intensity (think 10–30) or range.
  • Highlights blown / muddy → it's ACES rolling off; lower intensity, or accept the soft shoulder.
  • Want a thing to glow more → raise its emissive_intensity (or a light's intensity) past the bloom threshold. Brighter = bigger halo.

Colour / mood

  • Wrong overall cast → swap ColorGrade preset (F2).
  • Shadows too black → lift ambient, or grade.lift.
  • Cold vs warm zone → tint both ambient and grade the same way.

Surface feel

  • Too plasticky/shiny → raise roughness.
  • Flat / no relief → bind a normal_texture, then set normal_strength 0.3–0.6.
  • Seams between wall boxes → set triplanar: true.
  • Texture too big/small → uv_scale (or repeats/metre in triplanar).

Atmosphere

  • No depth/flat space → raise fog density + falloff.
  • Want a visible beam → fog scattering > 0 and spot god_ray_intensity > 0.
  • Beam too washed out → lower fog density, lower ambient.
  • Tense framing → Vignette::OPPRESSIVE (F3).
  • Soft dreamy glow / "too sterile" → raise Bloom (F7: Faint → EraGlow). Too hazy → lower strength or raise threshold.
